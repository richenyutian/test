# Form Edit Studio

基于 Vue3 + Element Plus 的前端表单设计与填写示例项目。

## 功能说明

- 表单管理
  - 新增、编辑、删除表单模板
  - 字段设计：输入框、文本域、下拉、数字、日期、开关
  - 校验设计：必填、长度范围、正则、提示文案、触发方式
  - 布局设计：列数、标签位置、标签宽度、栅格间距、组件尺寸
- 表单填写
  - 选择一个已发布模板进行填写
  - 按模板规则进行前端校验
  - 提交后记录最近提交结果
- 本地持久化
  - 表单模板和提交记录保存在 localStorage

## 启动方式

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
